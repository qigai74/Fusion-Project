# 聚变计划 · 圆方战记

> 自动战斗模拟器 —— 圆点是人类，方块是僵尸。
> 单个 HTML 文件，零依赖，零构建，双击即玩。

这是**聚变计划**下的一个作品。聚变计划是一个创作汇总企划，
涵盖小说、视频与游戏等多个方向。

---

## 怎么玩

**最简单**：下载 `圆方战记.html`，双击打开。就这样。

不需要安装、不需要联网、不需要服务器。建议用 Chrome / Edge。
Windows 上也可以双击 `启动游戏.bat`。

### 操作

| 操作 | 功能 |
|---|---|
| 左键拖拽 | 框选部队 |
| 右键点地面 | 派遣选中部队 |
| 空格 | 暂停 / 继续 |
| S | 切换速度 1× / 2× / 4× |
| R | 重打 |
| N | 显示队伍编号 |
| L | 点击指挥开关 |
| E | 回到配置 |
| F | 全屏 |

## 三种模式

### 常规对战
双方自由编队，全歼对手。可以自定义每支队伍的兵种、数值、行为预设、地图。

### 撤离任务
带领救援队深入**迷宫型**城市地图，把平民带回撤离区。
- 你只能指挥人类，僵尸永远是敌方 AI
- 僵尸从远端洞口成波涌入
- 平民会被感染 —— 救得慢就变成敌人

### 预算模式
**预先知道地图和敌军总规模**（数量 / 波数），但看不到具体兵种。
用一笔固定预算组建队伍，花完为止。

- 难度档与地图**独立选择**（5 难度 × 9 地图 = 45 种组合）
- 兵种价格由战斗价值自动推算
- 附带「用算法配一队」功能，也可以手动加减
- 敌军编成是隐藏的 —— 打起来才知道

## 地图

### 自制地图
在「⑤ 地图」页可以直接用画笔绘制，支持：
- 墙（全掩体）/ 窗（半掩体，人类可翻越但很慢）/ 门（僵尸需撞开）
- **预设出生点**：在地图上点出队伍出生位置与僵尸刷怪点
- 镜像绘制、随机生成、地图体检

### 保存与分享
- **保存**：存在本机浏览器，可保存多张
- **导出 / 导入文件**：`.json` 格式，可以带走、可以分享
- **分享码**：把地图压成一段短字符串（约 150~970 字符），
  直接粘贴到聊天里就能传给别人 —— 这是社群互传地图的主要方式

> 分享码格式：`FUS1-<尺寸>-<地形>-<出生点>-<刷怪点>`
> 地形用「每字节 4 格」的紧凑编码 + URL-safe base64。
> 任何截断或篡改都会被拒绝并给出明确原因。

### 随机地图
「随机」按钮会生成一张全新的地图，自带体检
（连通性 / 出生区 / 门窗密度），不合格会自动换种子重试。

## 玩法细节

### 感染与尸变
人类被僵尸咬中后进入 3 秒感染窗口。窗口结束前没被医疗兵治好，
就会**当场尸变并倒戈**加入僵尸一方。

### 兵种
- **人类（9）**：步枪手、狙击手、机枪手、霰弹枪手、医疗兵、平民、喷火兵、火箭兵、盾卫
- **僵尸（5）**：僵尸、跑尸、僵尸母体、大胃袋、终极母体

盾卫的盾牌**永不可破**，正面完全免疫伤害，盾击带击退与硬直。
终极母体每 12 秒随机孵化 2 只僵尸（跑尸 / 僵尸 / 大胃袋 / 母体，不含自己）；
普通母体只孵普通僵尸。

### 行为预设
自由行动 / 游击 / 主动出击 / 坚守。框选部队后切换会**立即生效**。

## 开发者 / 改代码

源码拆成几个片段，用 `_build.js` 拼成单文件：

```
_shell_head.html   HTML 外壳 + CSS
_script_a.js       引擎 A：常量 / 兵种 / 单位 / 伤害 / 音效 / 网格
_script_b.js       引擎 B：AI 行为 / 阵法 / 战斗 / 渲染
_script_c.js       引擎 C：UI / 输入 / 模式系统 / 调试接口
_shell_tail.html   收尾
_brand.js          ★ 作品名与版本（改这里，全站生效）
_build.js          构建脚本
_test.js           回归测试（329 项）
移交文档.md        完整开发历史与踩坑记录
```

```bash
node _build.js      # 产出 index.html 与 发布/
node _test.js       # 必须看到「全部通过」
```

**改名**：只改 `_brand.js` 里的 `NAME`，重新构建即可。

### 调试接口
浏览器控制台里有 `window.QB`：

```js
QB.start({h:'42222', z:'84', preset:'balanced'})
QB.simulate(30)
QB.setMode('budget')          // normal / mission / budget
QB.budgetPresets()            // 预算模式难度档
QB.shareCode('地图名')         // 生成分享码
QB.randomMapReliability(20)   // 检查随机地图可靠性
```
